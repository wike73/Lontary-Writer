Contributing to Lontary

First of all, thank you for your interest in contributing to Lontary!

Lontary is an open software project developed by Wike Adhi Anggono. Contributions, suggestions, improvements, and ideas are welcome.

We believe that software development should be open, collaborative, and accessible to everyone.

How to Contribute

There are several ways you can contribute to Lontary:

Report Bugs: Help us identify problems or unexpected behavior.
Suggest Features: Share ideas for new features and improvements.
Improve Documentation: Help make project documentation clearer and easier to understand.
Submit Code: Contribute code improvements, fixes, or new functionality.
Share Ideas: Discuss ways to make Lontary better.
Getting Started

If you want to contribute code, follow these steps:

Fork the Lontary repository.
Clone your fork to your local computer.
Create a new branch for your changes.
Make your modifications.
Test your changes.
Commit your changes with a clear description.
Submit a Pull Request to the original Lontary repository.
Contribution Guidelines

Please follow these simple guidelines:

Keep your code clean and readable.
Write clear commit messages.
Avoid unnecessary changes.
Explain important modifications.
Test your changes before submitting a Pull Request.
Be respectful and helpful to other contributors.
Pull Requests

Pull Requests are welcome!

When submitting a Pull Request, please:

Describe what you changed.
Explain why the changes are necessary.
Include relevant information about testing.
Reference related issues if applicable.

All contributions are subject to review before being merged into the main project.

Code of Conduct

All contributors are expected to:

Treat everyone with respect.
Be welcoming to beginners.
Avoid harassment or discrimination.
Provide constructive feedback.
Maintain a positive and collaborative environment.
